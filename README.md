# UPPAAL Models and Supplementary materials

This repository contains the UPPAAL models and supplementary materials of our study.

## Overview

-The UPPAAL models represent clinical decision-making processes and treatment pathways implemented in UPPAAL.
-The Supplementary materials contain Supplementary Tables 1-5 and Supplementary Figures 1-3.   

The repository includes:
-Supplementary materials
-UPPAAL_github.zip
 - Basic models used for methodological evaluation
 - Case study models
 - Models with and without PK/PD assessment
 - Verification queries used in the analyses
